# Krabi coast: modern / 1967 comparison

Interactive transparency comparison and three downloadable images.

- Historical imagery: USGS CORONA, 2 April 1967.
- Modern imagery: Esri mosaic; capture dates unverified. Credits: Esri, Vantor, Earthstar Geographics and GIS User Community.
- The blue outline is an approximate parcel screen trace, not a surveyed boundary.
- Historical alignment is approximate. Small offsets are not necessarily landscape changes.

The page is static and has no sign-in requirement. No seller contact or offer is made by this page.
